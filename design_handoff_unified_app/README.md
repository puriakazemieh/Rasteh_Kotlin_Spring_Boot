# Handoff: اپلیکیشن بازارچهٔ محلی (Local Marketplace App)

## Overview
یک اپلیکیشن موبایل بازار محلی/پاساژ (مثل ترکیبی از دیوار، شیپور، باسلام و ترب) با سه نقش کاربری در یک اپ یکپارچه: **خریدار (customer)**، **فروشنده (vendor)** و **ادمین پاساژ (admin)**. کاربر می‌تواند فروشگاه‌های یک پاساژ فیزیکی را ببیند، محصولات را بخرد یا برای بازدید حضوری برنامه‌ریزی کند، فروشگاه‌ها را دنبال کند، و از ۲۰ قابلیت ویژه (لایو‌شاپینگ، خرید گروهی، تخفیف ساعتی، مسیریاب داخل پاساژ و…) استفاده کند.

زبان رابط کاربری: **فارسی، راست‌به‌چپ (RTL)**. اعداد به‌صورت ارقام فارسی (۰۱۲۳۴۵۶۷۸۹) نمایش داده می‌شوند.

---

## About the Design Files
فایل‌های این بسته **مرجع طراحی‌اند که با HTML ساخته شده‌اند** — پروتوتایپ‌هایی که ظاهر و رفتار مورد نظر را نشان می‌دهند، نه کد آمادهٔ تولید (production) برای کپی مستقیم.

`Unified App.dc.html` یک **Design Component** است: یک `<x-dc>` template به‌همراه یک کلاس منطقی (`class Component extends DCLogic`) که توسط `support.js` رندر می‌شود. تمام استایل‌ها inline هستند و کل اپ یک single-page state machine است که با متغیر `screen` بین ~۶۰ صفحه سوییچ می‌کند.

**وظیفهٔ توسعه‌دهنده:** این طراحی‌ها را در محیط واقعی کدبیس مقصد بازسازی کند (React / React Native / Vue / SwiftUI / Flutter و…) با الگوها و کتابخانه‌های همان کدبیس. اگر محیطی وجود ندارد، مناسب‌ترین فریم‌ورک را انتخاب کنید. **این HTML را مستقیماً به تولید نبرید.**

پیشنهاد معماری برای بازسازی:
- یک **Router** واقعی به‌جای متغیر `screen` (مثلاً React Router / Expo Router). هر `screen` = یک route.
- **State**: احراز هویت/نقش، سبد خرید، دنبال‌شده‌ها، ذخیره‌ها، پیام‌ها در یک store سراسری (Zustand/Redux/Context).
- **RTL**: کل اپ `dir="rtl"`. از logical properties (`padding-inline`, `margin-inline`) استفاده کنید.
- **i18n + اعداد فارسی**: یک helper برای تبدیل ارقام لاتین به فارسی (معادل `faDigits` در طراحی).

## Fidelity
**High-fidelity (hifi).** رنگ‌ها، تایپوگرافی، فاصله‌ها، شعاع گوشه‌ها و تعاملات نهایی هستند. UI را پیکسل‌به‌پیکسل با کتابخانه‌های موجود کدبیس بازسازی کنید. مقادیر رنگ در فرمت **oklch** آمده‌اند؛ می‌توانید مستقیم از oklch استفاده کنید (پشتیبانی مرورگرهای مدرن) یا معادل hex/HSL بسازید.

## نقش‌ها و ناوبری
سه نقش با یک سوییچ نقش (customer/vendor/admin). Bottom-nav چهار/پنج‌آیتمه در صفحات اصلی خریدار: **خانه، جست‌وجو، ذخیره‌ها، پیام‌ها، پروفایل**.

نقش فروشنده و ادمین **درون تب پروفایل به‌صورت inline** نمایش داده می‌شوند (نه صفحهٔ جدا): با انتخاب نقش، در همان صفحهٔ پروفایل آمار + میان‌برها + لیست‌های مربوطه ظاهر می‌شود.

## Screens / Views
اپ ~۶۰ صفحه دارد. صفحات با `state.screen` سوییچ می‌شوند. گروه‌بندی:

### احراز هویت
- **login (ورود)** — ورود با شمارهٔ موبایل.
- **signup (ثبت‌نام)** — نام + موبایل + گزینهٔ «می‌خواهم فروشنده شوم».

### خریدار — اصلی
- **feed (خانه)** — هدر: انتخاب شهر (کلیک → citySelect)، لوگو، زنگوله (badge اعلان)، آواتار (→profile). نوار جست‌وجو. چیپ‌های دسته‌بندی افقی. تب «فروشگاه‌ها/محصولات». سپس:
  1. بنر گرادیانی **«امکانات ویژهٔ بازارچه»** (→features).
  2. ردیف افقی **«فروشگاه‌های دیده‌شده اخیر»** (آواتار دایره‌ای).
  3. ردیف افقی **«فروشگاه‌های دنبال‌شده»** (کارت ۱۵۸px با badge هدیهٔ دنبال‌کننده روی کاور؛ فقط اگر کاربر فروشگاهی دنبال کرده باشد). دکمهٔ «مدیریت» → manageFollowing.
  4. لیست **«فروشگاه‌های بازارچه»** (کارت‌های افقی با کاور، نام، تأیید‌شده ✓، badge نوع «خرید آنلاین»/«بازدید حضوری»، امتیاز، طبقه، وضعیت باز/بسته). دکمهٔ «نقشه پاساژ».
  - تب محصولات: گرید دو‌ستونه کارت محصول.
- **search (جست‌وجو/فیلتر)** — فیلتر دسته، قیمت، برند، وضعیت (نو/کارکرده)، مرتب‌سازی.
- **shopDetail (صفحهٔ فروشگاه)** — **سبک باسلام**: کاور گرادیانی، آواتار دایره‌ای روی کاور (margin-top منفی ۳۴px)، نام + تیک تأیید، دسته/طبقه، badge نوع. نوار آمار سه‌بخشی (**دنبال‌کننده / رضایت / عملکرد**). دکمه‌های **«دنبال کردن / دنبال می‌کنید ✓»** (toggle، حالت فعال = پس‌زمینهٔ روشن بنفش + بوردر) و **«پیام»**. تب‌های: **محصولات، حراجی، ویترینو (کارت بزرگ)، نظرات (میانگین امتیاز + لیست)، اطلاعات (about، آدرس، تماس، ساعات، وضعیت چت، دکمهٔ مسیریابی، گزارش تخلف)**.
- **listing (جزئیات محصول)** — **سبک ترب**: گالری تصویر با نقطه‌ها، عنوان، badge وضعیت، قیمت. برای محصولات خرید‌آنلاین: **انتخاب مدل** (chip)، بخش **«فروشندگان دیگر این کالا»** (لیست فروشنده با آواتار، تیک، امتیاز، طبقه، قیمت؛ ارزان‌ترین با بوردر سبز و badge «ارزان‌ترین»؛ انتخاب شهر) + لینک «مقایسهٔ همه» → compare. کارت فروشگاه، توضیحات، افزودن به سبد.
- **cart (سبد خرید)** / **orderConfirm (تایید سفارش)**.
- **chatList / chatThread** — لیست و رشتهٔ چت با فروشنده.
- **bookmarks (ذخیره‌ها)** — تب محصولات/فروشگاه‌ها.

### خریدار — پروفایل و منو
- **profile (پروفایل)** — هدر کاربر، سوییچ نقش (customer/vendor/admin). منوی customer: کالاها و سفارش‌های من، **فروشگاه‌های دنبال‌شده** (→manageFollowing)، فعالیت‌ها، امکانات ویژه، امتیاز و نظرات من، کیف‌پول، دعوت دوستان، تنظیمات، پشتیبانی.
- **manageFollowing (فروشگاه‌های دنبال‌شده)** — لیست فروشگاه‌های دنبال‌شده با دکمهٔ **«لغو دنبال»** برای هرکدام و کارت **«هدیهٔ دنبال‌کننده»** (کد تخفیف اختصاصی مثل FOLLOW15، دکمهٔ استفاده). حالت خالی با آیکون قلب.
- **activity (فعالیت‌ها)** — فید فعالیت (پسند/ذخیره/پیام/دنبال) با آواتار و آیکون نوع.
- **citySelect (انتخاب شهر)** — جست‌وجوی شهر، «استفاده از موقعیت فعلی»، لیست شهرها با تیک انتخاب.
- **editProfile، myListings، myReviews، settings، support، wallet، referral، notifications**.

### فروشنده (inline در پروفایل + صفحات)
- کارت فروشگاه + نوار آمار (بازدید امروز/پیام جدید/سفارش در انتظار) + گرید میان‌بر:
  **افزودن محصول، مدیریت محصولات، سفارش‌ها، ویرایش فروشگاه، آمار و عملکرد، تخفیف دنبال‌کننده‌ها، کد QR فروشگاه** + لیست «آخرین محصولات من».
- **addProduct (افزودن محصول)** — چند اسلات عکس (عکس اصلی + افزودن)، نام محصول، دستهٔ‌بندی، قیمت، وضعیت (نو/کارکرده)، **موجودی**، **درصد تخفیف**، توضیحات، دکمهٔ «ثبت محصول». (حالت موفقیت: صفحهٔ تأیید با دکمهٔ بازگشت به مدیریت.)
- **manageListings** — لیست محصولات با وضعیت (فعال/در انتظار/رد/متوقف).
- **vendorOrders، editShop، vendorAnalytics، shopQr**.
- **becomeVendor (افزودن فروشگاه)** — نام، دسته، طبقه، **نوع فروشگاه** (خرید آنلاین/فقط بازدید حضوری)، **شمارهٔ تماس**، **آدرس دقیق**، **ساعات کاری**، **دربارهٔ فروشگاه**، و کلیدهای toggle **«چت درون‌برنامه‌ای»** و **«پذیرش پیشنهاد قیمت»**. دکمهٔ ثبت و ارسال برای تأیید.
- **followerPerk (تخفیف دنبال‌کننده‌ها)** — کارت گرادیانی قرمز با تعداد دنبال‌کننده. **کد تخفیف فعال** (FOLLOW15، ۱۵٪، آمار استفاده). فرم **ساخت کد جدید** (عنوان، درصد) + کلید «نمایش قیمت ویژه به دنبال‌کننده‌ها». دکمهٔ ساخت و اعلام.

### ادمین (inline در پروفایل + صفحات)
- کارت مدیریت پاساژ + نوار آمار (در انتظار تایید/گزارش باز/فروشگاه فعال) + گرید میان‌بر (تایید فروشگاه‌ها با badge، گزارش تخلف با badge، افزودن سریع فروشگاه، سوپروایزرها) + لیست «در انتظار تایید».
- **adminDash** با تب‌های approvals/reports/quickAdd/supervisors؛ **reportDetail (بررسی گزارش)**.

### ۲۰ قابلیت ویژه (features launcher → هر کدام یک صفحه)
`features` یک گرید دو‌ستونه از ۲۰ کاشی است. صفحات:
1. **concierge** دستیار خرید هوشمند (چت‌بات با کارت پیشنهاد محصول)
2. **wayfind** مسیریاب داخل پاساژ (نقشهٔ طبقه + مسیر خط‌چین + pin)
3. **live** لایو‌شاپینگ (ویدئوی زنده تمام‌صفحه + چت + کارت محصول خرید)
4. **flash** تخفیف‌های ساعتی (شمارش معکوس زنده + نوار موجودی)
5. **groupbuy** خرید گروهی (نوار پیشرفت ظرفیت + آواتار شرکت‌کننده‌ها)
6. **loyalty** باشگاه وفاداری (کارت طلایی + QR + امتیاز + جوایز)
7. **appointment** رزرو نوبت حضوری (انتخاب روز/ساعت)
8. **compare** مقایسهٔ فروشندگان (لیست قیمت + ارزان‌ترین)
9. **escrow** پرداخت امن امانی (تایم‌لاین مرحله‌ای)
10. **tracking** ردیابی زندهٔ سفارش (نقشه + پیک + مراحل)
11. **returns** مرکز بازگشت کالا (انتخاب دلیل + آپلود عکس)
12. **giftcard** کارت هدیه (کارت گرادیانی + مبلغ + ارسال)
13. **warranty** دفترچهٔ ضمانت دیجیتال (لیست + نوار اعتبار)
14. **events** رویدادها و جشنواره‌ها (کارت رویداد + لیست تاریخ)
15. **community** انجمن محله (پست‌های اجتماعی + کامنت)
16. **pricealert** هشدار کاهش قیمت (نمودار روند + قیمت هدف + toggle)
17. **stories** استوری فروشگاه‌ها (نوار استوری + نمای تمام‌صفحه)
18. **vipsub** اشتراک ویژه «بازارچه پلاس» (کارت مزایا)
19. **parking** پارکینگ من (محل پارک + هزینه + پرداخت)
20. **visualsearch** جست‌وجوی تصویری و صوتی (کادر دوربین + نتایج تطابق)

## Interactions & Behavior
- **ناوبری**: هر عنصر دارای `onclick` که `screen` را تغییر می‌دهد (`data-s="<screen>"`). دکمهٔ back در هدر هر صفحه به صفحهٔ والد برمی‌گردد.
- **دنبال‌کردن فروشگاه**: toggle در shopDetail و manageFollowing؛ state مشترک `followedShops` (map از shopId به boolean). دنبال‌کردن باعث نمایش کارت فروشگاه در خانه و دسترسی به کد تخفیف دنبال‌کننده می‌شود.
- **سبد خرید / ذخیره‌ها / پیام‌ها**: state مشترک با badge.
- **تخفیف ساعتی (flash)**: تایمر ثانیه‌ای زنده (`setInterval` ۱۰۰۰ms؛ پس از صفر ری‌ست). فرمت `HH : MM : SS` با ارقام فارسی.
- **انتخاب مدل/تب‌ها**: انتخاب فعال با تغییر رنگ/بوردر مشخص می‌شود.
- **toggleها**: چت درون‌برنامه‌ای، پذیرش پیشنهاد قیمت، هشدار قیمت — سوییچ‌های سبز/بنفش.

## State Management
متغیرهای اصلی state (از طراحی):
- `screen` — صفحهٔ فعلی (در کد واقعی = route).
- `role` — `customer | vendor | admin`.
- `city` — شهر انتخاب‌شده.
- `cat, price, brand, condition, sort` — فیلترهای جست‌وجو.
- `homeTab` (`shops|products`), `shopTab` (`products|sale|showcase|reviews|info`), `bookmarkTab`, `adminTab`.
- `followedShops` — map از shopId → boolean.
- `bookmarks`, `shopBookmarks` — map ذخیره‌ها.
- `cart` — map از productId → quantity.
- `messages`, `notifReadIds`, `notifBadge`.
- `flashSecs` — شمارندهٔ تخفیف ساعتی.
- `selectedShopId`, `selectedProductId` — برای صفحات جزئیات.
- `productForm`, `shopForm*` — فرم‌های ورودی.

انتقال‌ها با هندلرها: `goScreen`, `openShop`, `openListing`, `setCat`, `setHomeTab`, `setShopTab`, `toggleFollowShop`, `unfollowShop`, `addToCart`, `setCity`, `setRole` و…

## Data Models (برای پیاده‌سازی API)

## Assets
- **بدون تصویر واقعی**: تمام تصاویر محصول/فروشگاه با **ایموجی** روی پس‌زمینهٔ رنگی placeholder نمایش داده شده‌اند. در کد واقعی با تصاویر واقعی جایگزین شوند.
- **آیکون‌ها**: همه inline SVG (stroke-based، stroke-width ~1.7–1.8، `stroke-linecap/linejoin round`). مسیرها در object `ICONS` تعریف شده‌اند؛ می‌توانید با یک کتابخانهٔ آیکون (Lucide/Heroicons) جایگزین کنید — سبک بصری مشابه Lucide است.
- **فونت**: Vazirmatn از Google Fonts.
